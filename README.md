# Landing Page — Escola DNC

Landing page desenvolvida como projeto prático para aplicação de conceitos de desenvolvimento web, utilizando HTML5, CSS3 e JavaScript.

O projeto reproduz uma página institucional para divulgação de um curso introdutório de tecnologia, contendo apresentação do curso, vídeo, informações sobre a formação, carrossel de depoimentos e formulário de inscrição.

## 🔗 Demonstração

**Acesse o projeto publicado:**
[https://luizzvictorino.github.io/projeto-landingPage/](https://rad-chaja-1bf60f.netlify.app/)

## 📋 Sobre o projeto

O projeto consiste no desenvolvimento de uma landing page responsiva inspirada em uma página de divulgação educacional.

O objetivo principal foi aplicar conceitos fundamentais de desenvolvimento Front-End, incluindo estruturação semântica com HTML, estilização com CSS, manipulação de elementos através de JavaScript e organização de arquivos em uma estrutura de projeto adequada.

Além da implementação da interface, o projeto também foi publicado utilizando o **GitHub Pages**, permitindo seu acesso diretamente pela internet.

## ✨ Funcionalidades

* Landing page institucional;
* Layout estruturado em diferentes seções;
* Integração com vídeo do YouTube;
* Seção informativa sobre o curso;
* Carrossel de depoimentos;
* Navegação através de controles em JavaScript;
* Formulário de inscrição;
* Integração do formulário com serviço externo;
* Layout adaptado para diferentes tamanhos de tela;
* Hospedagem utilizando GitHub Pages.

### Principais arquivos

**`index.html`**
Responsável pela estrutura e conteúdo da landing page.

**`css/style.css`**
Contém as regras de estilização, layout, tipografia e responsividade.

**`js/script.js`**
Responsável pelas interações e funcionalidades desenvolvidas em JavaScript.

**`assets/`**
Armazena imagens, ícones e elementos gráficos utilizados na interface.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/luizzVictorino/projeto-landingPage.git
```

### 2. Acesse a pasta do projeto

```bash
cd projeto-landingPage
```

### 3. Execute o projeto

Por se tratar de uma aplicação Front-End estática, não é necessário instalar dependências.

Basta abrir o arquivo:

```text
index.html
```

em um navegador.

Para uma experiência de desenvolvimento mais adequada, recomenda-se utilizar uma extensão como **Live Server** no Visual Studio Code.

## 🌐 Deploy

O projeto está hospedado através do **GitHub Pages**.

A cada atualização publicada na branch configurada para o GitHub Pages, a versão disponibilizada no ambiente de produção pode ser atualizada automaticamente conforme a configuração do repositório.
